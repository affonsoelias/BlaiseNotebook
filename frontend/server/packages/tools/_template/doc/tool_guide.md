# 🛠️ Official Tool Template Guide

This directory is an **optional documentation folder** for storing markdown documentation (`.md`) accompanying this auxiliary tool.

## Structure
* `uToolTemplate.pas`: Auxiliary Pascal unit.
* `package.json`: Tool manifest metadata (`category: "tool"`).
* `README.md`: Quick summary.
* `doc/`: Optional extended documentation.
* `examples/`: Optional example notebook (`.bynb`).
